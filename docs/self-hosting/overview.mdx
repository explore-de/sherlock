---
title: Self-hosting Sherlock
---

Build Sherlock from this repository using the root README. For a container build, run:

```sh
docker build -t sherlock:local .
```

Use your own configuration and persistent data storage when deploying. Never reuse a database from a newer version without a migration plan.

The default repository list is empty. Configure repositories through a [configuration file](/self-hosting/more/declarative-config), or enable authentication and use repository connections in the app.

Analytics are disabled by default. External mail, authentication, telemetry, and billing services require your own accounts and configuration. Hosting location, retention, TLS, backups, and access policy are the instance administrator’s responsibility.
